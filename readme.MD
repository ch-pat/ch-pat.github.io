# Patryk Choma — personal website

This repository contains my personal portfolio, built with Astro and deployed as a static site on GitHub Pages.

## Run locally

Requires Node.js 22.23.4 or newer and npm 9.6.5 or newer.

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

The production site is written to `dist/`. See [REDESIGN.md](./REDESIGN.md) for the design and technology rationale.
